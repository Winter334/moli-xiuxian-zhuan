# 内容测试控制台

更新：2026-10-03。

## 身份与入口

- 正式Discord Activity也可用，入口在顶栏“更多选项”，**普通玩家不显示入口**。
  服务端复用`SOCIAL_MODERATOR_IDS`的已验证Discord用户ID名单，默认空；
  与[聊天管理](social-system.zh-CN.md#世界频道)共用身份配置，不接受前端自报权限。
- 服务端环境文件填逗号分隔的管理员ID，重启/更新服务后生效。
  部署继续走[更新保护流程](discord-activity.zh-CN.md#更新与验收)，不为开放控制台操作数据库。
- 每次提交均重新核对Discord会话及名单，只能调整管理员自己的当前角色。
  普通玩家即使手工调用接口也被拒绝；会话或权限失效后关闭入口，不暂停正常本地游玩。
- 本机非Discord开发模式继续直接使用；`/?preview=ui`仍只操作内存预览，不请求角色接口或写存档。
  正式构建不开放这个预览入口。
- 不是任意脚本执行器；不提供清档、回退、重置挑战、存档导入覆盖或时间加速。

## 操作内容

按成长、物资、修习、地图四类组织。气运、物品、技能与地点可按名称/效果搜索，
物品另按类别筛选；列表显示当前状态。常用数量、品质、金额及累计值可一键填入，
修为提供“下一境界所需”，技能提供“设为满级”。先选对象再点明确的提交按钮，
处理期间禁用重复提交，面板顶部显示结果或错误。

| 操作 | 实际行为 |
| --- | --- |
| 提升境界 | 选择当前已接境界中高于当前的目标，只补不足修为；保留已有超额修为，复用晋升满血及神通取得，不发正常履历奖励；首次筑基可选人道/地道/天道，已有根基不可更换 |
| 增加修为 | 追加精确累计修为，沿正常晋升和突破前封顶，不借追加操作自动筑基 |
| 更换本世气运 | 从当前28种气运中选一个替换，立即重算派生属性；不重抽、不叠加、不轮回，不改变世次、技能、物品或随机数状态 |
| 增加化悟值 | 筑基后追加精确化悟值，不改变灵髓已吸收记录 |
| 清除旧测试标记 | 仅在旧档有标记时显示；移除该标记并同步，不改履历累计、首次记录或角色进度 |
| 提升炉鼎 | 向前提升至当前已接炉阶，不扣材料，不修改配方或技能 |
| 气血回满 | 按当前装备、功法及补给后的实际气血上限补满，不改敌人、药效或时钟 |
| 增加灵石 | 增加可交易余额，不是行囊灵石物品；单次1–10^12，累计沿整数字符串长度和整档大小校验，不受库存数量上限限制 |
| 发放物品 | 从当前内容表选择；堆叠物品单次最多10000，炼材/装备独立实例最多100件 |
| 器物品质 | 10–999的整数，默认100；创建独立实例，不自动装备、出售、消耗或抽取随机品质 |
| 取得技能/功法 | 取得当前目录中的未学技能，同时补齐必要地图前置；不自动运转，不发战斗奖励 |
| 提升熟练度 | 提升到所选等级的累计门槛，不扣已有累计；旧存档尚未写入的两类精通沿现有派生进度起算 |
| 增加累计熟练 | 精确追加，满级后继续累计，但不超过等级与效果上限 |
| 补前置并前往 | 完成所选区域的必要前置，前往其安全据点；目标区域自身保持原进度，可自行进入挑战 |
| 跳过并完成 | 同时补齐前置和所选区域，不减少已有累计清理组数；不发击杀、清图经验或掉落 |
| 补前置并传送 | 选当前已实现安全地点，补齐其开放条件后传送；离开战斗/安睡并进入歇息 |

地图操作会撤出当前敌群，不结算为胜利。控制台不接入未实现的地图、技能或后期系统；
正常游戏的取得、消耗与气运随机规则不变。

## 存档边界

- **改动写入当前角色，不可撤销。** 用户明确控制台主要用于本人在联机环境快速验证新增内容，
  只需管理员身份，不附加测试资格限制；成功操作不再打永久测试标记，
  不因使用控制台限制Discord榜单、寄售或其它联机功能。近期操作记录仍保留。
  旧存档字段保持兼容，已有旧标记可用专门按钮清除，也会随下一次成功控制台操作清除；
  不自动批量改写数据库或其他角色。
- `GET /api/client/debug`仅查询权限；`POST /api/client/debug`验证身份后在独立快照执行命令，
  返回结果，不直接写数据库。客户端仍走串行队列，本地保存成功才更新画面；
  原有在线计时与已发生的战斗不回退，迟到的旧会话结果不落盘。
- 普通云上传只有再次验证管理员身份才允许本世`fateId`改变或旧测试标记清除，
  不再要求测试标记为真；其余履历、进度、计时和资产校验不放宽。
  换运或清除旧标记与待上传请求一起本地落盘并立即尝试备份；
  轮回、寄售或PVP继续前须确认该备份。上传失败保留本地及原请求，
  不允许换运或清标记绕过待确认请求；其余控制台改动参加原有低频云备份。
- 输入先校验，执行后重算派生属性并检查完整性及容量。
  无效参数、未取得技能、越界等级或超量只报操作错误，测试改动不落盘。
- 继续遵守实例总量、材料总量、存档大小、身份、版本、计时及云端冲突检查。
  真正的本地存储失败仍暂停；不会为测试进度强制覆盖冲突云档。
- 不改角色/本地/云端保存结构或版本，不新增数据库迁移。
