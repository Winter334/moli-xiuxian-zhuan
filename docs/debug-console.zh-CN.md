# 内容测试控制台

更新：2026-09-28。
境界调试复用正常晋升奖励/满血结算，已有超额修为不扣除或归零。

## 要求与工作默认

- 用户要求增加测试用作弊控制，快速推进内容，免去等待挂机。
- 本批工作默认：顶栏终端图标展开操作面板，仅开发模式启用；不是任意脚本执行器。
  不添加后端作弊接口，不放宽现有云存档校验，不将测试操作纳入正常成长或奖励。
- 境界、熟练度、清图只向前修改，不提供清档、回退、重置挑战、导入覆盖或时间加速。
  不增加新内容，不恢复离线战斗结算。

## 实际接入

开发服务 `pnpm play` / `pnpm dev` 的顶栏提供“测试控制台”终端图标。
打开控制台本身不会修改角色；每项操作单独提交，正常战斗计时不因展开面板而暂停。

| 操作 | 实际行为 |
| --- | --- |
| 提升境界 | 选炼气1–12层或筑基初期中高于当前的目标，只补不足修为；复用晋升节点满血，首次筑基同时取得抱元罡，不自动装备 |
| 气血回满 | 按当前装备、功法及补给后的实际气血上限补满，不改敌人、药效或时钟 |
| 增加钱袋 | 直接增加可交易余额，不是行囊铜钱；默认1000文，单次1–10^12文，累计仍受存档上限限制 |
| 发放物品 | 从当前内容表选择，默认10份；材料/补给/灵髓/心得单次最多10000，器胚/装备最多100件 |
| 器物品质 | 10–999的整数，默认100；创建独立实例，不自动装备、出售、消耗或抽取随机品质 |
| 提升熟练度 | 选择已有技能或已领悟功法，提升到所选等级的累计经验门槛，保留各自等级上限 |
| 补前置并前往 | 完成所选区域的必要前置，前往其安全据点；目标区域自身保持原进度，可自行进入挑战 |
| 跳过并完成 | 同时补齐前置和所选区域，不减少已有累计清理组数；不发击杀、清图经验或掉落 |
| 补前置并传送 | 选当前已实现安全地点，补齐其开放条件后传送；离开战斗/安睡并进入歇息 |

地图操作会撤出当前敌群，不结算这次退出为胜利。通过测试完成挑战后，
功法仍需在对应地点正常领悟，然后才会出现在熟练度选择中；不自动学习或运转。
未接入地图、新商铺及后期系统不出现在控制台中。

## 存档边界

- **测试修改作用于当前角色，本地自动保存，并参加原有60–75秒云备份；不是临时预览，无法撤销。**
  控制台有明确警告，近期记录以 `[测试]` 标识操作。
- 操作走同一个客户端串行队列，本地保存成功后才更新画面；不增加逐次网络请求。
  提交前正常推进的在线时间照常保留，不回滚已经发生的战斗。
- 输入先校验，再在独立快照上修改、重新计算派生属性并检查完整性。
  无效参数、未领悟功法、越界等级或超出存档容量只报操作错误，测试改动不落盘。
- 继续遵守实例总量、材料总量、存档大小、身份、版本、计时及云端冲突检查。
  真正的本地存储失败仍暂停；不会为测试进度强制覆盖冲突云档。
- UI及客户端分发均用 `import.meta.env.DEV` 限制，开发模块按需导入；
  非开发模式的测试调用直接拒绝。该限制不是竞技级反作弊。
- 无角色/存档结构变更，不做迁移或兼容，不读取、清空或覆盖实际角色来验证控制台。
