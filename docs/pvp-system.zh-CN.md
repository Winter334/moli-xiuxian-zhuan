# PVP袭击与安全区

更新：2026-10-02。状态：云端准入、安全区、袭击、恶名、红名锁定及穿戴装备转移已接；
本机定向验证完成，VPS部署与真实Discord双端验收待进行。

## 已确认规则

- 玩家主动开启PVP模式才可发起或遭受袭击，双方须同地点、在线且均已开启。
  开启代表持续接受袭击，不逐场征求被攻击者同意；红名不能关闭，刷新或换设备不解除。
- 主动攻击非红名玩家并获胜增加恶名；被攻击者防卫获胜、主动讨伐红名不增加恶名。
  达到阈值变为红名；仅被其他玩家击败才解除红名，恶名归零，妖兽战败不解除。
- 败者气血归零、中止当前活动并回对应安全点；非红名不损失装备。
  红名败者随机失去一件当时穿戴的可转移装备，由胜者获得；不掉行囊物品、
  钱币、商盟托管或待领取资产。没有可掉落装备时不补造损失或奖励。
- 红名攻击者落败时，被攻击者同样获得掉落装备；自动防卫不要求观看或操作战斗。
  接受玩家提前换廉价装备、安排他人击败来洗红的可行性，不追加复杂关联追踪。
- 首版只做单挑，不附加PVE收益、修为或熟练奖励，不扩入天梯、悬赏、阵营或组队战。

## 单方推演与结算

攻击者通过服务器按需获取双方最新战斗检查点，在客户端用现有战斗引擎逐帧推进，
直接进入中央原有战斗场景；双方使用玩家行动规则，共享命中、暴击、连击、减伤、
效果到期与恢复计时，不另写简化伤害或独立战斗循环。气血、蓄力、出手和伤害反馈
复用现有战斗卡，展示双方核实的名字、头像与境界；左侧气血同步显示交锋状态。
战斗结束或主动撤退后才提交胜负，由服务器结算，不提前算完后播放战报。
被攻击者不看战斗过程：
防卫获胜只收到日志及可能的装备所得，落败则收到日志并执行败退。
现在的常态公开资料不包含当前气血与临时效果，不能直接用于袭击。

服务器核对身份、云档修订与完整性、同地点、模式、在线状态及双方会话占用，
绑定固定会话编号、快照和结果。双方先保存本地检查点再提交，核对期间暂停本地推进、
命令与上传；服务器同时拒绝新存档提交、寄售变更及轮回，不能卸下或转卖候选装备。
败退、恶名、装备转移与双方持久回执一起提交，正常重试只结算一次；
回执只应用与冻结检查点匹配的气血、败退、装备及日志变化，不拿旧快照覆盖无关进度。
结算同时递增双方云档修订及资产修订，旧云档与本地副本不能跨过已确认PVP结果。
恶名与模式由独立服务器记录保存，不能靠刷新、采用旧云档或轮回清除。

开战前目标无响应则袭击不成立，不把无响应当作目标落败；
已经受理后攻击者不提交结果，按攻击者撤退失败终结，避免无成本试打。
攻击端关闭页面后不补算战斗；真正挂起或计时间隔超过5秒时，该段时间不推进交锋。
服务器不重算战斗，基础一致性与事务保护不等于能证明攻击端胜负报告绝对真实。

## 工作默认与断线

集中参数位于`shared/pvp.ts`，为首版工作默认，后续按体验调整：

| 项目 | 当前值 |
| --- | --- |
| 主动击败非红名 | 恶名+1，达到3转红名 |
| 模式切换 | 冷却5秒；关闭不清恶名 |
| 袭击间隔 | 成功受理防卫检查点后冷却10秒 |
| 败退保护 | 败者30秒不能发起或遭受袭击；红名锁定不因此解除 |
| 准备等待 | 10秒内未取得有效防卫检查点，取消，不结算胜负 |
| 结果等待 | 受理后150秒未完成结算，攻击者按撤退失败结算 |
| 战斗上限 | 实际推进120秒仍未分胜负，攻击者败退 |

双方都用玩家属性、攻速、命中/暴击、连击、伤害修饰与临时效果计时规则；
不运行PVE敌人技能、掉落或成长钩子。同刻行动按攻击者先出手，击败对方后不再反击，
不产生双败；临时气血上限变化结算时按检查点上限换算，避免旧药效属性残留。
装备从败者当时穿戴槽等概率选择，品质不变、胜者得到新的本地实例编号；
阶段援助器物巡枢残印不参与转移，空槽及未穿戴器物不进入候选。

本地格式4的`pendingPvp`兼容可选的战斗快照与引擎检查点，旧存档直接接续，不提高保存版本。
攻击端每次推进先保存双方气血、随机状态、剩余效果与出手计时，再显示战斗变化；
刷新后从保存的交锋检查点继续，不重新开战或补算关闭期间时间。
已经生成胜负后只重试原战斗编号与原结果；原角色在匹配回执落盘前仍冻结，
重开恢复联机前再次比对结算后云档。回执不符、云档或资产修订过期则停止联机并保留原件，
不能通过存档恢复丢弃未决会话。服务器重启后从数据库继续核对与超时处理。
达到时限或战斗结束后进入结算状态；撤退同样按攻击者落败结算。
被攻击端始终无战斗场景或回放弹窗。

## 安全区

安全区由已有`SAFE_LOCATIONS`目录明确提供，不根据是否正在战斗或已经清理临时推断。
目前14处全部禁止发起PVP，包括讨伐红名：

| 地域 | 安全地点 |
| --- | --- |
| 开局与出山 | 槐溪村、隐居者石室、灰脊避风坪、石桥镇 |
| 望川 | 望川外埠、临风演武台、望川西市 |
| 涵岳 | 涵岳外台、涵岳前庭、内院阵台、暖泉静室 |
| 百渠与照野 | 千渠埠、百渠堤口、照野道口 |

所有`REGIONS`历练区与挑战区仍是非安全区，首清后停留也不转为安全区。
败退目的地沿原区域的`parent`映射；安全区允许红名进入与休整，不解除模式锁定。
安全区与调息资格独立，调息地点及普通歇息见[调息专题](meditation-rework.zh-CN.md)。
地图和地点页已展示两类信息，服务端袭击入口同样拒绝所有安全区请求。
