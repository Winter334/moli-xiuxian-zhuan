# 石桥镇至望川外埠：区域内容与实施记录

承接[石桥镇与芦滩首轮](opening-content-relations.zh-CN.md#11-石桥镇与芦滩首轮实施记录)，

## 1. 确认方向与工作选择

**用户已确认**：按区域逐批完善设定和内容；城镇与场景要越来越宏大，
体现逐步脱离凡俗、步入仙道的趋势。背景优先适配已有规则，不预防性调整数值。
出山后的交易点归属四海商盟，村口仍由村民自行组织。

**本批工作默认**：石桥镇所在河流汇入沧流江，沿江旧陆路通往更大的望川城。
本批只接到望川外埠，不一次实施整座城或全部周边。
沧流江、望川城、各段路名与具体设施均为创作补充，不表示用户逐字定稿。

| 已走过的层次 | 场景尺度与日常事物 | 修行接触如何加深 |
| --- | --- | --- |
| 槐溪村及近山 | 柴坡、溪谷、村落交换 | 养生口诀与偶见含灵之物，生活以凡俗为主 |
| 石桥镇及芦滩 | 跨河石桥、两岸街市、小型舟运 | 商会收购妖皮和铁料，低阶修士与凡俗货运并存 |
| 沧流江沿岸至望川外埠 | 宽江与支峡、长堤、成排码头、依岸展开的城街 | 分水舟纹、航道阵灯、运货灵舟及封装灵材进入日常交通与装卸 |

规模增长由河流、建筑群、交通与物资共同表现，不只把“村”改为“城”或堆叠仙家称谓。
望川只是玩家目前接触到的较大修行城镇，不是世界中心；
更大城池和更高层次的日常仍留给后续。玩家抵达这里不等于已有筑基的话语分量。

## 2. 地点、经历与开放

| 内部定位 | 原名称 → 当前名称 | 存在理由、玩家经历与原有开放关系 |
| --- | --- | --- |
| `market-outer-road` | 坊外长道 → 汇川长堤 | 镇河与大江汇流的堤岸，水面货运仍在运转，探索发生在堤脚林路；清理回水深滩后开放 |
| `old-ferry-bank` | 古渡荒滩 → 沧流故渡 | 新埠兴起后留下的旧渡岸，支涧与密林藏有妖物及劫掠者；长堤清理后开放，保留双敌遭遇 |
| `stone-gate-pass` | 镇石关 → 悬江石梁 | 跨过临江支峡的天然石梁，汲脉石魁盘踞窄处；故渡清理后开放，保留单敌一次挑战 |
| `cloudfoot-waystation` | 云麓驿 → 望川外埠 | 更大城镇的外侧码头与歇脚石廊；石梁挑战后开放，保留原往返、邻接与调息许可 |

玩家在首镇补充行装后，沿已有路线接触更广的物资流通与修士聚居地。
沿途所得既可带回石桥商会出售，也能保留作炼制、炼化投入；没有必须离镇或禁止折返的规则。
战斗位于商路外围和旧岸，主航道与新埠仍正常运转，不把整个修行社会写成无人维护的废墟。
石魁是自然凝成的地脉生灵，不是官方城卫、商盟拦关者或选拔新人的试官。
通过石梁承接原进度条件，不新增船票、乘舟、入城身份、境界门槛或护送任务。

**外埠当前没有商店**。商盟仓楼只是可见背景，不开放仓库、提货或寄售；
望川全城与城中商会尚未实施。截至本段路线，交易仍在村店和按原进度开放的石桥商会进行，
后续已有商铺按各自原条件运行，不能将外埠描写等同于全部商会已适配。
本批三个战区仍归属石桥镇，撤退按原逻辑返回所属安全点；没有因更名改变撤退落点。

## 3. 敌人与物资

八种敌人新增描述，其中四种更名；已适配的裂爪泽魈与施毒劫修继续共用。

| 敌人 | 内容承接 |
| --- | --- |
| 黑巾劫修 | 尾随携货行人后突然出刃，承接原一次入场攻击；铁片护臂与钱袋对应原物资 |
| 游荡刀修 → 截舟刀修 | 在小舟野泊处劫掠落单者，刀刃与铁料货包承接原铁料来源，不将普通行路刀修视为敌人 |
| 伏涧妖猿 | 从支涧岩缝和树冠跃下连续挥爪，承接原三次入场攻击与皮肉来源 |
| 逆纹妖狐 | 妖纹扰乱攻守气机，承接交锋时玩家攻防倒置；不是反伤、闪避或永久属性改变 |
| 横练散修 → 横练劫修 | 以劫掠为敌对原因，凝实筋骨对应既有面板，不新增减伤或格挡能力 |
| 叠符邪修 → 叠符劫修 | 轻符后接重符，承接原0.8、1.2两段攻击；劫来的灵髓仍是原概率掉落 |
| 披木山魈 | 以铁桦硬枝与树皮裹身，承接木料、肉与韧妖皮来源，不额外增加坚固能力 |
| 镇关石魁 → 汲脉石魁 | 地脉灵气凝成岩躯，玄灵髓嵌在躯壳中、地脉浊露积于关节，保留原固定掉落 |

披木山魈也用于后续区域，共用描述随之更新，不表示后续战区已经适配。
各敌人的面板、能力、敌池权重与掉落不变，既有材料不必为每一项另造生态或搜刮规则。

玄灵髓、地脉浊露保留名称，新增来源与用途描述：

- 玄灵髓仍可炼化养身，也仍是已有灵髓晶配方的投入；本批不提前发放其它所需材料。
- 地脉浊露仍与青纹矿、地火煤用于熔炼青纹铁，配方保持矿2、浊露1、煤1。
  先保留或出售均沿用已有规则，不新增采露点，也不将岩壁描述变成免费资源。
- 汲脉石魁仍固定掉落两份玄灵髓和两份地脉浊露，不增发通行凭证、宝箱或装备。

炼化、炼制和出售互有取舍，同一份灵材不能重复计作全部收益。
沿途原有铁料、妖皮和肉料继续有用，不为表现仙道层次而删除凡俗来源或抬高炉鼎成本。
