# 凝霜冰宫内容设计

更新：2026-10-07。状态：整区框架、采冰与商契、商店成长、激灵环及水牢接口已认可，未实施；逐敌与成品细案待细化。当前作为后续设计预案，不纳入本次化神接入范围。
承接[凝霜雪原](ningshuang-snowfield-content.zh-CN.md)。来源为references/NekoRPG/src的
极寒冰宫区域、采冰活动、Sky II商店、物品、制作与溪月对白；以实际代码为准。

## 1. 地域与路线

原冰城拟为凝霜冰宫：凝霜秘境中心的冰砌城阙，城坊与宫院相接，长街、冰渠、
高台和封闭院落可见。不是又一段雪坡，也不将全部建筑写成自然冰洞。
原四区拟名冰阙外街、环霜长廊、寒械内坊、凝光上庭；各20组、基础三敌，
首清/重复修为150亿/50亿、225亿/75亿、300亿/100亿、450亿/150亿。
前两区原光环参数0.12保留，后两区不凭背景增加同等增幅；特殊能力额外敌人另核。
终点四位封庭守老承接原敌意老人挑战，同场4敌、光环参数0.50，非单只首领。
其模板基础气血326.7亿、攻击4.5亿、防御3亿、敏捷3.9亿、攻速1.4；原spec5，
空物品掉落表保留，胜后开放人物交流，不能因首领称谓新增装备奖励。

冰宫战士与术士可表达为被旧禁制驱使的守御造物，混有本地生灵和外来修士；
不把一切都化为虚影。原溪月拟为泠月，秘境主人遗留的管理器灵，不能杀死玩家或
改写全世界规则。她引导进入下一层，但不揭露诸域之战、仙路断绝真相。

## 2. 采冰与商店成长

原冰宫入口即有无限采矿活动，基础熟练200/次；技能区间40–60对应周期24–1秒，
资源配置为冰块概率0.96–1、数量区间从1到9–10；冰髓概率0.03–0.30、一份；
商人概率0.01–0.10、一份。沿原技能曲线，不误写为每次必出三种或线性时间概率。
这不是后续地层钻探小游戏，不新增采冰工具槽或冻伤规则。

原冰宫商人是可出售物品（5.21兆），使用一件增加已救商人数N，首次开放商店；
商店有效人数n=min(N,9999)，库存倍率n^0.8，品质加值9ln(n)，原计数不因封顶归零。
数量按原向上取整；新倍率在原换货时生成，不因登记重抽已有库存。
建议物品改为冰封商契，出售承接物资契约转让，使用承接协助被困商队恢复供货；
保留原取得、消耗、价值与计数，不把活人作为商品，也不改成新声望或每日任务。
这一交易对象的叙事替换已获认可，不删出售或多次使用功能。

本店不一到区域就自动营业。原利润参数4.8、间隔2日沿公共历法与议价规则。
基础库存含凝相灵核、鸣律灵金、原能量冰沙、玄寒灵液、空窍冰晶、晶化三兵刃、
冰髓四外甲、极寒四内甲、冰宫鳞片、光环杖芯、镶晶盾牌、冰髓及概率0.2的玄冰果。
外甲映射为现有升炼材料形式，成品细案另筛，不以列出库存等同全部交叉配方批准。

## 3. 材料与特殊饰物

冰宫鳞片拟霜宫鳞；光环杖芯拟环辉灵芯；镶晶盾牌拟嵌晶护片；
晶化合金改称霜华金，避免原候选“凝晶灵金”发音重复；极寒织料拟玄霜灵绡。
原冰髓2＋护片3＋鳞1→霜华金3（等级27–62、成功率0.5–1）；
空窍冰晶2＋环辉灵芯2＋鳞1→玄霜灵绡1，原等级40–60、成功率0.3–1。
后者延续原防御型基础衣装，与垂星攻防型比较后筛成品。

光环法杖拟激灵环，仍为饰物槽。原用灵芯69＋霜华金99＋觉醒玄冰果9，
等级49–63、成功率0.5–1、固定品质200、价值864兆。
对适用普通敌人生成时的光环系数加0.25，非固定把已有敌人再乘1.25；
面板气血/攻防敏随系数H变化，基础经验乘H^1.5、适用掉落乘H，攻速不变。
原无增幅时经验比约1.3975；已有区域增幅时相对收益不固定39.7%。
首领与原rank>=4000范围无效，保留敌人源范围，不仅凭显示境界判断。
不影响PVP、不强行占其它槽位，不因它增加挑战性就归为原创玩法。

## 4. 水牢接口及批次边界

终点挑战后通过泠月的原功能交流开放下一层，暂名封澜水牢。
原入口连接可回冰宫，对白亦承认能离开，因此不新增禁回城、装备没收或必须杀光才能离开。
下一批保留强者挑战、选择分支、六普通区、水系领悟、1440档休整与十四阶炉的设计职责，
不把水牢只当传送过场。原竺虎处置分支另给晶化剑品质239、肉5和259346107197056货币，
以及后续人物奖励须随水牢核对，不在本批预发或删减。
时间与传承完整机制继续按实际生效节点查证，不因时封命名新增公共时钟变速。
