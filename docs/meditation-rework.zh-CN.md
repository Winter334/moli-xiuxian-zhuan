## 2. 已接入规则

| 项目 | 实际行为 |
| --- | --- |
| 可用地点 | 由安全地点的 `meditation` 配置独立决定；未配置的安全点也不开放 |
| 战斗中操作 | 拒绝调息，必须先按原规则撤退；不因点击调息自动撤退或改变当前敌群 |
| 撤退与再入场 | 沿用原逻辑：回到所属安全点、未完成敌群作废、已清组数保留；重新进入重新生成遭遇并执行入场规则 |
| 操作互斥 | 开始调息会停止训练或采矿；调息中直接炼制、精炼、合炼、升炼、养鼎或开始训练/采矿，会自动结束调息并执行该行动；原有材料、地点和开放条件不变 |
| 失败行动 | 行动未通过校验时保留调息、资源及随机状态，不先提交一次停止调息再尝试行动 |
| 页面浏览 | 切换页面、查看配方/物品详情或地图不打断调息；结束调息仍保留手动入口 |
| 停止与出发 | 停止调息回到普通歇息；移动或进入可达战区会结束调息，不增加额外确认或通行前置 |
| 装备与用物 | 保留原有并行操作，不主动结束调息，不增加调息专属禁用、增益或消耗 |
| 恢复 | 每秒恢复 `round(max(气血上限 × 10%, 5))`，之后结算原有固定与比例回复，包括负面代价 |
| 普通歇息 | 保留原有 `max(气血上限 × 2%, 2)` 恢复；未开放调息的安全点也不因此失去普通被动歇息 |
| 养息 | 保留独立养息熟练、等级与奖励；基础熟练按已达到的原解锁进度取最高档，所有允许调息点通用 |
| 修为 | 调息本身不产出修为、击杀、掉落或战斗熟练度 |
| 离线 | 安全地点歇息与调息沿用已有离线休整；保留气血、养息和药效计时，不自动进入战斗；公共日期独立持续前进 |
| 关闭时仍在战斗 | 原封保留敌群、气血及剩余计时，重开继续；不补奖、不回血、不自动撤退或重抽 |
