# 大战余波：世界历史与后续地域

日期：2026-09-29。版本：工作稿0.2。
配套：[世界观0.4](world-setting-rework.zh-CN.md)、[主线0.4](mainline-first-arc.zh-CN.md)。
本稿落实用户新补充及授权创作的历史细节，历史编制批次只更新设定。
后续[涵岳内院](hanyue-inner-content.zh-CN.md)已将局部撤迁、封停痕迹接入运行描述；
完整战史、远期地域与新机制仍未接入。
最新已确认先后：仙路断绝在前，正魔大战在后。大战的真实原因不同于世间流传版本，
更加复杂，并保留牵涉成仙之秘的方向。当前玩家境界低微，尚接触不到这些秘密，
为后续保留设计空间，具体真相与两者的因果关系暂不提前设计。

## 1. 用户已确认的主轴

- 一场大事件导致世界格局大洗牌，人族从巅峰繁荣跌落，不少旧地域被妖物、邪祟占据。
- 高阶修士斗法可以把原本繁荣的地域打成绝地。绝地不是山险路难的别称，
  而是存在连修士也很难克服的极端力量；同时保留天然形成、并非战争造成的绝地。
- 高阶修士重伤后坐化，可以留下秘境与传承，形成后续探索内容。
- 筑基前可以以遗迹为主要探索内容，之后随着境界提高逐渐安排绝地、秘境等，
  不要求以后每一段都围绕废弃建筑展开。
- 助手可自行敲定部分普通设定和延伸内容，仍须区分用户主轴、创作补充、待设计规则和实际实现。
- 当前修仙界仙路断绝，已经很久没有修士飞升成仙；这是已确认世界事实，不只是传闻。
- 仙路断绝先于正魔大战发生，先后已确定；断绝的具体原因目前未知。
- 正魔大战背后的真实原因不是世间广为流传的版本，原因更复杂，并保留牵涉成仙之秘的方向。
  用户明确此处不提前设计，先不确定真相、相关人物或揭示过程。

“正邪大战”最初是用户举例，后续已以正魔大战为背景补入真实战因的留白。
“诸域之战”名称、年代、下列流传版战因与具体地域仍是创作补充，不写成用户逐字确认。

## 2. 历史框架与流传版本：诸域之战

### 盛世与世间流传的战因

工作名称定为“诸域之战”，发生于当今之前数百年，精确年代和诸宗名称暂不填写。
凡人社会已经更迭许多代，高阶修士中仍可能存在亲历者；不因此改变角色个人历法。

战前人族处在长久经营积累的繁盛时期，仙城、宗门别院、灵田、工坊与跨域商路
深入今日已经失守的地域。各地并非同属一个帝国，但宗门与城域之间有稳定往来。
昔日繁荣来自几代乃至更久的生产和维护，不是所有凡人都能修仙，也不是随处有至宝。

世间广为流传的说法是：部分魔道大宗为强行突破，以炼化大片灵脉及生灵的禁法侵夺多处灵域，
引发正道诸宗联合讨伐。宗门同盟、附属城域和旧有争端将战事逐步卷向各地，
最终发展为波及整个修行界的长期大战。
后期的征调、报复与争夺远超最初战场，参战者的利益和行为不完全一致。

以上作为流传版本的工作文案保留，不再充当作者层面的真实起因。
真实原因更复杂，但这也不等于上述说法中的每件事都必然为假。
哪些内容属实、遗漏或误传，以及是否有人有意改写，都留待以后，不在此处预埋答案。

### 仙路断绝与真相留白

当前修仙界仙路断绝，已经很久没有修士飞升成仙。
先后顺序已确认：仙路断绝在前，正魔大战在后。
仙路断绝的具体原因与年代、它与大战之间的具体因果，以及成仙之秘的内容，仍未设计。
因此不将大战写成仙路最初断绝的原因，也不能仅凭先后就断定“仙路断绝必然引发大战”。
幕后人物、上界状况、重续仙路的方式及玩家最终如何参与，同样不提前确定。

当前内容中的玩家境界低微，尚接触不到这些深层秘密。
暂缓展开是为了给后续设计保留空间，不是将这些内容永久排除出世界观。
这项世界事实不改变当前修为增长、境界突破或资源取得规则，
也不自动为玩家安排修复仙路的必然使命，当前阶段不投放能坐实某种答案的线索。

### 战争结束，旧格局未能恢复

战争以多个主要参战势力覆灭、分裂或重创退守而结束，没有一方恢复对旧世界的完整控制。
高阶战力损失、人口迁移和经营体系断裂，使人族失去大片原本能长期维持的地域。
有些繁盛地区直接毁于斗法，有些完好的城院失去庇护与维护，后来才被妖物、邪祟占据。
妖物不必全是邪修的部属：许多只是在失去压制后繁衍、迁入或聚众据地。
邪祟的来源也可以不同，包括禁法残留、死地积聚和失控的修行设施。

如今旧日大宗有的只剩一隅，新兴宗族占据新的产地，原来的腹地可能变成危险边地，
曾经偏僻的渡口则因旧商路被截断而发展成新的城镇。
大战已经结束，不等于地域和生活已经回到巅峰；人族的衰退也不等于文明全部断绝。
仍有强者、繁盛大城与稳定生产，但它们能维持的范围、彼此联系的能力已不同于从前。
不预设全世界灵气统一衰竭，不把“人族衰退”直接解释成所有修士都无法继续突破。

四海商盟工作默认在战前已有跨域经营基础，战时也遭受损失。
战后各地需要重新连接产地与城域，尚能维持远程商路的商盟因此拥有更大影响力。
它连接分散的繁盛地区，却不意味着每一条旧路都已恢复、每一片旧土都在其掌控之下。
本稿只确定其商贸职责，不提前安排它在战争真相中的角色。
已确认的外界交易点归属不变，也不新增价格、库存或交通规则。

## 3. 遗迹、险地、绝地与秘境

| 类型 | 核心来由 | 内容侧重 |
| --- | --- | --- |
| 普通险地 | 山野生灵、自然环境与资源分布 | 生长、捕食、采料与行路风险；不能仅因道路险峻就称为绝地 |
| 遗迹 | 曾经有人长期生活、修行或经营的地方 | 旧用途、撤离或破坏的方式、后来占据者及尚能利用的物资 |
| 后天绝地 | 高阶斗法或禁法留下长期存在的极端力量 | 残存真火、剑意、扭曲灵机等本身就是危险，不只是留下一个大坑或几只强怪 |
| 先天绝地 | 天地长期形成的极端力量汇聚之地 | 早于大战存在，不必找到人为事故才能解释其危险 |
| 秘境 | 与寻常地域有所隔绝的独立灵域或小天地 | 自身环境、资源与内部空间；可以天然形成，也可以由前人开辟经营 |
| 传承秘境 | 修士将道统、所藏与经营之地留存于秘境 | 传承者的具体所学、生活与遗留安排，不默认都是逐关奖励的试炼场 |

这些类型可以相交，却不是一条由低到高的难度等级表。
绝地中可以有古城遗迹，秘境里也可以存在正常山水与局部绝险之处。
一处高阶斗法遗留的力量可以与当地地脉纠缠、长期往复，解释为何战后很久仍不能正常居住；
其强弱、边界与影响按具体地域设计，不把所有遗迹都套上同一种“战后污染”。

高阶修士伤重坐化留下传承，本稿采用“原有或先行开辟的秘境被保留下来”的工作默认。
不是每次坐化都凭空生成一座秘境，也不要求所有秘境都由死者留下。
有的修士安排了继承，有的只来得及封存功法和私藏，还有的疗伤居所后来才被发现。
玩家进入其中不自动成为唯一传人，更不因此获得包办后续成长的全部家底。

## 4. 涵岳山院的具体来历

以下为授权创作补充；内院已呈现部分现场痕迹，完整历史仍是设定背景：

涵岳原是一处宗门经营的炼养山院，借灵泉与地火浸养灵木、炼材和制造工傀，
供给附近修行聚落，也向更远的宗门驻地运送器料。
它不是宗门核心，也不是开局隐居者的故居或高阶修士的传承试场。

大战期间，院中人员和成品不断被调往外地，维护水火设施与工傀的人手逐渐不足。
所属势力后来收缩驻地，剩余人员撤走，带走便携贵重器物，留下难以搬运的设施、
未完工器胚和仍按旧令运行的傀儡。此后水路淤塞、阵枢失修，妖物逐渐进入院群。
这是一处受大战间接影响而被放弃的生产山院，不采用“全院在一夜间被屠尽”的原因。

如今散修在前庭休整、商会驻留收售灵材，说明旧地可以被局部重新利用，
不等于整座山院的供给与维护已经恢复。
涵岳不是绝地，不把低阶玩家能应对的旧傀和阵灵说成高阶强者完整威能的残留。
深层敌人的来由继续围绕停用设施、侵入生灵和寻材者展开，不预定最终首领是大战中的某位大能。

现已在封渠地廊呈现封停支口，在涵岳丹坊呈现空运器架、拆卸卡槽和迁运石刻，
在分火悬台呈现已卸走的铜环与仍在聚火的旧阵。
后续巡枢长廊、育材石窟补入拆空阵匣、撤走的育材匣和侵入石床的菌苔、蛛网，
暖泉静室则保留轮值修士日常休整的用途；这些设施不自动恢复生产或增加采集玩法。
这些细节表明当地曾撤运器物、封停设施，不直接讲明战时征调或所属势力退守的完整过程，
也不涉及真实战因与成仙之秘。调拨记录等其余载体尚未投放，
不自动增加搜集任务、证据道具或功能前置。
已有浅层设施用途和取得关系保留，不追改全部物品为战争纪念物。

## 5. 后续地域工作种子

以下名字和来历作为可继续使用的工作默认，尚无地图节点、敌人配置、奖励或境界门槛。
不要求全部出现在紧接筑基后的第一批内容中。

| 工作名称 | 定位 | 具体设定 |
| --- | --- | --- |
| 照烬原 | 后天绝地 | 原是数座城镇相连的丰饶平原。高阶修士交战留下的真火与地脉纠缠，灰白地表虽不见明焰，残存火势仍能灼炼修士护身法力；城址保存多少与危险强弱分别处理，不是普通地火谷换名 |
| 寒寂海 | 先天绝地 | 早于大战存在的极阴海域，深处寒潮能凝滞真元与神识，并非加厚衣物即可克服的严寒。战后旧航路变化使人更常接触其外围，其形成不归因于战争 |
| 栖霞小界 | 传承秘境 | 一位高阶修士战伤难愈，退入自己经营的小界疗伤，最终坐化。山湖、灵园与居所保留其生前用途，封存的法门和手札构成传承；不默认留下完整考核、认主器物或唯一继承人 |

先介绍每处地方是什么、为什么存在，再按实际阶段决定玩家能够触及哪一部分。
不能只换更宏大的名字却继续把所有敌人、资源与场景都写成同一座废弃山院。

## 6. 阶段展开与实现边界

筑基前仍以遗迹为主要探索内容，保留村野、江路、自然灵地等已有地域。
当前不提前投放真正绝地的核心威能或完整高阶传承，也不因新历史重做首次筑基取得链。
玩家先看到被放弃的院群和今日聚居地，再逐渐认识到它们属于一个失去大片旧土的修行世界。

筑基及以后随实际内容扩大活动范围，逐步接触不同来由的遗迹、天然灵境和传承秘境，
再向与自身阶段相称的绝地区域推进。不规定“筑基必须进秘境、某境界必须进绝地”的固定菜单。
更高境界可以接触更直接的大战痕迹和仍在世的旧时代人物，但不要求主线转成收复人族故土或替前人复仇。
大战发生过及其地域后果不必包装成全世界守口如瓶的秘密，流传的战因与真实起因则必须区分。
具体旧地的经历可以通过现场细节逐渐补足，不因此让每处遗迹都掌握成仙之秘。

极端力量、神识受阻和秘境封存是本稿的世界描述，不代表当前已实现环境伤害、
新灵力/神识数值、抗性、寿元消耗、境界锁、钥匙、限时开放或全服唯一传承。
确需相关玩法时单独设计其资源与交互影响，不从背景直接增加规则。
不因为高阶修士曾经在场，就把原型敌人全部标成玩家正在击败的高阶本尊。

历史编制批次实际只更新设定、主线、区域关系说明和推进入口；当时源码、玩家可见运行文案、
数值、地图、存档及服务均未改，未操作实际角色或数据库。
只做文档回读与相关口径定向检索，文档变更可控、可预测，未运行测试或页面验收。
后续内院的实际改动、检查及下一批边界见[实施记录](hanyue-inner-content.zh-CN.md)；
继续以本稿来历组织局部内容表达，按原有规则逐批接入，不把设定落稿视为全部内容已完成。
