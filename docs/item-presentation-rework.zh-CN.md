# 补给、炼器与防具表达修订

更新：2026-10-01。状态：物品表达已接入，美术修正与确认状态见[素材清单](asset-manifest.zh-CN.md#物品系列与档次辨识)。
依据：[世界观讨论稿](world-setting-rework.zh-CN.md)、
[首段主线](mainline-first-arc.zh-CN.md)。

## 1. 确认方向与本批范围

用户已明确：

- 起步增益消耗品可以是肉干，后续逐步转向丹药。
- 武器制作不再表现为剑身、剑柄等零件装配，但保留现有规则。
- 原来可穿戴的内甲仍是完整装备，与加工后的防具呈现上下位关系，
  不能描述成没有独立用途的内衬材料。
- 防具可以是衣、巾、裤、履等服饰，使用材料升炼，不要求全部变成甲胄。
- 不改数值。

本批以“前两档凡俗食物，后续丹药”“精炼主材与淬炼辅料炼器”
“可穿防具与对应部位炼材升炼”为工作默认。
具体名称与描述可继续打磨，不把本稿名称当作用户逐字确认。
只改这些物品及相关制作、药效、操作提示，不批量改世界地名、敌人或其它历史设定。

## 2. 从行粮到丹药

| 原表达 | 本批表达 | 定位 |
| --- | --- | --- |
| 肉干 | 肉干 | 山村外出的便携行粮 |
| 精肉脯 | 精肉脯 | 前期较好的血肉滋养 |
| 灵膳肉脯 | 培元丹 | 将灵兽血肉精华凝炼成丹，开始进入修士药物 |
| 续脉散 | 续脉散 | 保留药散形态，不强求所有药物都是丹丸 |
| 燃血丹 | 燃血丹 | 保留短时强化与气血亏空代价 |
| 凝元羹 | 凝元丹 | 更深阶段的恢复与增益丹药 |
| 养元炙肉 | 养元丹 | 当前后段的恢复与增益丹药 |

对应制作名由烹炖改为炼制，效果名由“灵膳滋养”等改为培元、凝元、养元。
没有额外增加服丹修为、瞬回、丹毒、冷却或药效叠层。
效果数值、持续时间、同效续时、适用境界、售价、库存、产量和失败规则均未变。

原料仍按现有取得链供给。血肉可以提取精华，阵枢残核可以作为聚拢药力的炼制媒材，
不为了改成丹药额外加入灵草掉落、催生系统或一条新资源链。
媒材仍按原配方消耗，不增加可回收工具或返还收益。

## 3. 武器是炼成的器物

旧有两份独立品质投入，改为精炼主材与淬炼辅料。
两者都是加工后的炼材，不直接装备，不再借名字暗示缺一半的武器。

| 原角色 | 新表达 |
| --- | --- |
| 铁制剑身 | 百炼铁料 |
| 乌钢、青纹、玄煞、沉渊、鸣金剑身 | 对应的乌钢精料、青纹精料、玄煞精料、沉渊精料、鸣金精料 |
| 鸣金重剑身 | 鸣金重料 |
| 旧木剑柄 | 粗制淬液，由旧木料提炼 |
| 铁桦剑柄 | 桦脂淬液，由铁桦木提炼 |
| 养灵剑柄 | 养灵淬液 |
| 苏灵剑柄 | 苏灵淬液 |

成品按材质与炼制处理区分，不按剑柄命名。例如：

- 百炼铁料 + 粗制淬液 → 粗炼铁剑。
- 百炼铁料 + 桦脂淬液 → 铁剑。
- 青纹精料 + 养灵淬液 → 养灵青纹剑。
- 鸣金重料 + 苏灵淬液 → 苏灵鸣金重剑。

原低档剑柄的攻击、攻速等代价由粗制淬液承接；更好的辅料保留原有属性定位。
主材各档属性、重剑普攻倍率与熟练度、材料数量、成本、品质权重及熟练收益均未变。
不是把原不可装备的剑身改成可装备武器，也没有新增武器重复强化流程。

## 4. 防具从可穿到升炼

三组基础装备均能直接穿戴：

- 凡俗：夹皮头巾、夹皮短衣、夹皮长裤、软皮靴。
- 妖皮：妖皮护额、妖皮内甲、妖皮长裤、妖皮靴。
- 灵绢：回春巾、回春法衣、回春长裤、回春履。

原外甲部件改为三档细砂炼材，分别由青纹铁、玄煞铁、鸣金锭处理而成。
每档仍区分头、身、腿、足，名为束额砂、护衣砂、护腿砂、护履砂，
表示按不同部位所用纹式制备的独立一份炼材。没有合并四部位成本或品质。

升炼成品可以独立命名，不要求完整保留基础装备名称。
用户已明确“妖皮内甲 → 青纹妖甲”；上下位关系由配方表达，不必继续叫内甲。例如：

- 夹皮短衣 + 青纹护衣砂 → 青纹夹皮短衣。
- 妖皮内甲 + 青纹护衣砂 → 青纹妖甲。
- 回春法衣 + 鸣金护衣砂 → 鸣金回春法衣。

旧装备是升炼对象，不是给另一件成品垫在里面的材料。
基础内甲仍可独立穿戴，上位可以表现为妖甲；其它防具仍可使用法衣等服饰形态。
头、身、腿、脚四个槽位不变。
青纹、玄煞、鸣金的加成及代价保留，尤其不因叫“升炼”就删去玄煞的气血消耗。

### 规则边界

- 操作仍消耗所选原装备一件和对应炼材一份，生成上位装备一件。
- 原装备必须先卸下，品质按既有加权与随机规则重新判定。
  上下位是装备表达，不承诺任意品质投入都会使所有面板数值上升。
- 当前仍是三组基础防具分别选择各档炼材；已升炼成品不是下一次升炼的配方投入。
  没有新增连续升级、保留实例、继承原品质、拆解或材料返还。
- 处理后的装备继承原定义的属性组合；材料与装备的取得、价格和品质系数不变。

## 5. 文案约定与工程边界

物品描述先写材质、外观、制法和实际用途，再少量透露使用者的生活。
例如山民随身携带的肉干、铁匠使用的粗制淬液、反复缝补的软皮靴；
不把每件物品写成遗失传承或人物悲剧。
本批描述为工作稿，其它地点、怪物及器物的背景仍需按新世界观后续重写。

临时操作入口同步改为精炼主材、淬炼辅料、待升炼防具、升炼材料。
行囊与测试控制台中的“器胚”改称“炼材”；结果、错误提示和后续操作日志使用新表达。
没有重做布局或新增交互流程。

内部物品ID、配方ID、`food`、`part`、`blade/hilt`、`interior/exterior` 字段本批不重构。
它们继续承载现有结算，不再作为玩家可见名称。
没有新增兼容分支、存档转换或版本迁移，也没有读写实际角色；
已有存档日志中的历史文字不会被追溯改写。
