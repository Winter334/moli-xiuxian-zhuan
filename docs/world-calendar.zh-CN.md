# 统一世界历法

日期：2026-10-07。状态：统一历法已接入；化神及后续区域适配已确认、未实施。

## 1. 确认与工作默认

用户确认改用统一历法，调息移除加速时间的效果，其它效果保持不变。
这项决定覆盖此前“可加速个人历法”的口径，不恢复离线战斗，也不改为服务端逐次结算。

当前工作默认沿用原普通活动速度：现实30分钟为一个世界日。
统一纪元锚点为 `2026-09-29T00:00:00Z`，对应原本的初始日期“一年二月九日06:24”。
所有角色使用相同锚点和速度，与建角时间、境界、活动、养息等级无关；
世界日期在玩家关闭页面期间仍继续前进，不跟随角色的模拟进度暂停。
锚点之前的时间只显示起始时刻，不倒推世界历史。这个技术锚点不是仙路断绝或大战的设定年代。
原有年、月、日、时辰和月相换算保留，昼夜仍只作历法信息。

## 2. 玩家影响

- 化神不改变公共历法速度；中枢通关不执行原私人两年跳时、等待或收益补发。
  已确认的区域转场与逸灵余染按公共日消散规则由
  [灵舟后续](qixia-to-fallen-ark-content.zh-CN.md#58-凝晶与内舱后段本地化方案已确认)维护，尚未实施。
- 调息恢复、养息基础1/2/4档、熟练倍率、满级与气血里程碑全部保留。
- 移除原调息5倍、养息满级调息10倍的日期推进；不新增替代奖励或补偿。
- 药效仍使用模拟毫秒计时，不因世界日期变化提前到期或续时。
- 关闭/挂起期间战斗、训练和采矿仍暂停，不补发修为、熟练、击杀或掉落。
- 安全点歇息和允许点调息仍结算离线休整，许可和操作互斥不变。
- 系统商店仍是各角色、各店独立库存，仅换日依据改为统一世界日。
  访问、购买、出售时按当前世界日检查换货；跨过多天也只生成当日的一份库存，不累计补货。
  校时回拨到已换货的日期或更早日期不重抽，界面也不显示可再次换货。

相比原先主动调息赶日刷店，当前不能通过调息提早换货；
玩家离线或暂停战斗后回来则能遇到已经过去的公共日期。
每轮库存的内容、概率、数量、品质、价格与开放条件均未重调。
玩家寄售仍是独立设计，未因本批合并系统库存或接入玩家资产交易。

## 3. 时钟与保存

历法从独立的公共时间参数计算，不再存储角色累计历法分钟。
本地客户端以服务端时间样本为锚，页面打开期间用单调计时器推算；
本机系统时钟在页面运行中跳变不会直接推进日期或战斗。
日期显示与商店操作使用同一个公共时钟来源。

首次云端读取使用已有 `serverTime`；启动本地运行后以及每60–75秒，
通过只读 `GET /api/client/time` 校时，沿用低频云备份的调度间隔，互不等待。
该接口不读写角色、不要求上传进度、不参与战斗结算；
返回当前请求的服务端时间，不使用可重放上传回执中的旧 `savedAt` 校时。
有效样本补偿半个往返延迟，超过5秒的样本丢弃，避免页面挂起期间的响应扰乱日期。
校时不修改模拟时钟、战斗剩余时间、药效、随机状态、游玩时长或角色修订号。

本地保存公共时钟检查点，重开时按本机离线时间间隔推算，再尝试校准。
服务不可达时继续按上次样本推算，不暂停本地游玩；云上传因冲突停止也不会停用公共校时。
断网和离线时仍可能有本机时钟误差，不承诺严格同步或竞技级防作弊。
后续寄售的成交时间仍须由服务端确认，不能把此显示时钟当交易授权。

保存版本：

- 内核升至 `neko-kernel-4`，移除 `calendarMinutes` 和仅服务于日期加速的 `environment.restLevel`。
- 本地封装升至 `opening-local-2`，新增必填公共时钟检查点；沿用原存储键，遇到旧版本明确拒读并保留原数据。
- 角色 `neko-character-5`、云封装 `opening-client-1` 和内容 `neko-opening-2` 版本不变，
  但嵌套旧内核的角色和云快照同样拒读。
- 不自动补字段、迁移、截断、清库、搬运、重置或覆盖实际角色，数据库结构未改。
